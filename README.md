# TODO Application 
It is a beginner friendly project and gives us an in-depth knowledge about the frontend and backend parts of an application. This project has been developed using basic HTML, CSS and Javascript. It also provides an understanding of how the project grows through the development lifecycle.

# TODO APP - version 1.0.0

1. First the user has to sign up in order to create an account.
2. Then the user logs in to their account, but all TODO task entries are created afresh for each login session.
3. User array does not store the user account details once the express server shuts down. Those details are usable only till the express server is running in  the backend.(as of now)
4. The todo list associated to each user is empty everytime the user logs in. (as of now)
5. In the TODO page, there is delete button associated to each task, in case you want to delete that task.
6. A checkbox that will be clicked when that task is completed.
7. As soon as the checkbox of that task is clicked, it is moved to the completedTask list below. 
8. Logout button : When click the Logout button, it logs out of that session and displays you the login page again.



# TODO APP - version 1.1.0 

1. Use database to store the signed-up users and their tasks.
